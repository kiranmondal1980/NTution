## 🎯 System Architecture & The 4 Daily Questions
Every trading day, NSE MOMENTUM 5™ independently answers four core questions:
1. **What is the current NSE market regime?** (BULLISH / NEUTRAL / BEARISH)
2. **Which stocks have the strongest statistically validated momentum?** (Engine A: 0–100 Momentum Score)
3. **What is the empirical probability of achieving +5%, +10%, +15%, and +20% over 3–5 sessions?**
4. **For existing holdings, should I HOLD, TRAIL, PARTIAL BOOK, or EXIT?** (Engine B: Exit Intelligence)
